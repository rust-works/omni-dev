- **`chrono` replaced by `jiff`, clearing RUSTSEC-2026-0543** ([#2257](https://github.com/rust-works/omni-dev/issues/2257)): `chrono` is unmaintained with no patched release. Every timestamp omni-dev writes keeps its exact form (RFC 3339 in UTC with `Z` and 0, 3, 6 or 9 fraction digits; a commit's date in its author's offset, `Z` for UTC), so persisted files, daemon replies and the request log read the same as before. `rmcp` is updated to 3.12.0 with its `chrono` feature turned off, so `chrono` is no longer in the dependency tree. For library users, public fields and functions that took or returned `chrono` types now use `jiff::Timestamp` and `jiff::SignedDuration`, and `CommitInfo::date` is an `omni_dev::utils::time::OffsetTimestamp`. A Datadog `--from`/`--to` given as epoch seconds past 9999-12-30T22:00:00Z, the last instant `jiff` holds, is now rejected as an invalid time range.
