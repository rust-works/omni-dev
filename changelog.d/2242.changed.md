- **YAML dependencies replaced, clearing two RustSec warnings** ([#2242](https://github.com/rust-works/omni-dev/issues/2242)): the unmaintained `serde_yaml` (RUSTSEC-2024-0449, via `unsafe-libyaml`) is now `serde_norway`, an API-compatible maintained fork that keeps the same parser, and `yaml-rust-davvid` (RUSTSEC-2021-0153, via `encoding`) is now `yaml-rust2`. YAML output differs only for multiline strings: one that does not end in a newline is written as a `|-` block scalar (previously `|`, which read back with an extra trailing newline), and one that cannot be written as a literal block, such as a line with trailing whitespace, is quoted. Strings with CRLF line endings now round-trip.
