- **The library's secret-file writer is removed** ([#2225](https://github.com/rust-works/omni-dev/issues/2225)): `omni_dev::utils::secret_env::write_secret_file`, `plan_secret_file_write` and `SecretFileWrite`, with the `SecretEnvError::Unwritable` and `SecretEnvError::HoldsJson` variants only they returned, are gone. Their one user was the named Gmail and Drive account login, which moved to [gwi](https://github.com/rust-works/gwi) in [#2203](https://github.com/rust-works/omni-dev/issues/2203). Reading secrets (`secret_var`, `secret_var_any`, `read_secret_file`, `resolve_secret_pair` and the `_FILE`/`_COMMAND` companions) is unchanged, and no command changes behaviour. Rust code that called the removed items needs updating.
