- **BREAKING — Gmail and Drive (including Docs, Sheets and Slides) move to [gwi](https://github.com/rust-works/gwi)** ([#2203](https://github.com/rust-works/omni-dev/issues/2203), [ADR-0095](docs/adrs/adr-0095.md)): the `omni-dev gmail` and `omni-dev drive` command trees, their 23 MCP tools (`gmail_*`, `drive_*`) and the `omni_dev::gmail` and `omni_dev::drive` library modules are removed from omni-dev, along with the Gmail and Drive guides. Install gwi (binaries `gwi` and `gwi-mcp`, configuration in `~/.gwi/`) and run `gwi import` to copy your Gmail and Drive accounts, lease settings and Drive lease ledger from `~/.omni-dev`; the import copies and never modifies or removes the originals. Add `gwi-mcp` to your MCP client as a second server for the tools. Environment variables read by the moved code change prefix from `OMNI_DEV_` to `GWI_`; the unprefixed `GMAIL_*` and `DRIVE_*` credential names are unchanged. For this release `omni-dev gmail ...` and `omni-dev drive ...` remain as hidden stubs that accept any arguments and exit non-zero with a message pointing at gwi, its install instructions and `gwi import`; the next minor release deletes them. omni-dev's `Settings` no longer models the `gmail`, `drive` and `lease` blocks, but a `settings.json` that still carries them loads as before and keeps them across every write omni-dev makes to the file. `omni-dev log` still displays existing `drivemutation` and `audit` records, but omni-dev no longer writes `audit.jsonl` (Drive was its only writer) and never deletes an existing one. Anything that calls the removed library modules from Rust needs updating, so this is a breaking change for the next pre-1.0 minor release.
