- **Minimum supported Rust version raised from 1.88 to 1.92** ([#2242](https://github.com/rust-works/omni-dev/issues/2242)): `tao` 0.38, `tray-icon` 0.27 and `muda` 0.22, which the RustSec fix above needs, require rustc 1.92. Installing from source (`cargo install omni-dev`) now needs Rust 1.92 or newer; prebuilt binaries are unaffected.
